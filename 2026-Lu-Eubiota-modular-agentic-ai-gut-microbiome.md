# Eubiota: Modular Agentic AI for Autonomous Discovery in the Gut Microbiome

**Source:** [https://www.biorxiv.org/content/10.64898/2026.02.27.708412v1](https://www.biorxiv.org/content/10.64898/2026.02.27.708412v1)
**Created:** 2026-03-04

---

## Abstract

Eubiota is an open-source modular agentic AI framework designed for autonomous discovery in the gut microbiome. It decomposes microbiome inquiry using specialized agents for planning, execution, verification, and grounded synthesis. Coordinated through shared memory and domain-specific tools, Eubiota employs reinforcement learning to optimize multi-turn reasoning, achieving 87.7% benchmark accuracy and outperforming GPT-5.1 by 10.4%.

## Key Points

- **Modular Agentic Architecture**: Eubiota uses specialized agents (planning, execution, verification, synthesis) coordinated via shared memory
- **RL-Optimized Reasoning**: Employs reinforcement learning to optimize multi-turn reasoning chains
- **High Benchmark Performance**: 87.7% accuracy, surpassing GPT-5.1 by 10.4%
- **Experimental Validation**: Four case studies demonstrated end-to-end discovery with wet-lab validation

## Case Studies & Findings

1. **DNA Repair Axis Discovery**: Screened nearly 2,000 bacterial genes to identify the uvr-ruv DNA repair axis as a fitness determinant under inflammatory stress. Validated using transposon mutants and IBD metagenomes.

2. **Consortium Design**: Designed a four-strain bacterial consortium that attenuated colitis severity in mice.

3. **Antibiotic Cocktail**: Generated a commensal-sparing antibiotic cocktail, demonstrating utility for community-level design challenges.

4. **Metabolite Screening**: Discovered diet-associated metabolites that suppress NF-κB signaling.

## Methodology

- Multi-agent system with specialized roles
- Shared memory architecture for coordination
- Reinforcement learning optimization
- Integration with domain-specific tools and databases
- Grounded synthesis with experimental validation pipeline
